# 单作品拆解模板

> 用途：拆解任意一条内容时的标准化执行蓝图 + 报告输出骨架。
> 说明：本模板是对既有脚本链路的固化与抽象。
> 仅限自己内容研究使用，不传播。

---

## 一、标准执行流程（6 步）

每一步对应一个动作，输入作品 ID 即可跑通。**建议顺序执行，不要跳步。**

| 步骤 | 动作 | 产出 | 是否必做 |
|---|---|---|---|
| ① 证据采集 | 元数据 + 弹幕 + 评论 + 分章 | `deconstruct_<id>.json` | ✅ 必做 |
| ② 音频下载 | 拉取音频流 | `<id>.m4a` | ✅ 必做（需转写时） |
| ③ 转写 | 语音 → 文字（抗幻觉参数） | `<音频>.txt` / `.srt` | ✅ 必做（口播视频） |
| ④ 画面文字提取 | PPT 式 / 纯图视频的 OCR | `ocr_*/文字稿.txt` | ⚠️ 仅纯图视频 |
| ⑤ 生成报告 | 证据包 → 拆解报告 | `拆解-<id>.md` | ✅ 必做 |
| ⑥ 自动化验收 | 机器断言校验 | PASS / FAIL 清单 | ✅ 必做 |

### 一键全流程（可选）

```bash
python auto_deconstruct.py <bvid>                   # ①-⑤ 全自动
python auto_deconstruct.py <bvid> --no-transcribe   # 跳过转写（纯图视频）
```

---

## 二、各步骤关键参数（防踩坑）

### ① 证据采集

- 免登录接口：`view/detail`（元数据）、`x/v1/dm/list.so`（弹幕，zlib raw deflate 解压）、`x/v2/reply`（评论）
- 弹幕是**命根子**：唯一免费、带时间戳的情绪标注
- 评论要区分口径：平台总量（含已删 / 折叠）≠ 采集量，**不可混用**

### ③ 转写（抗幻觉参数，实测必须加）

```
-mc 0      不继承上文上下文（长音频重复幻觉主因）
-et 2.4    提高熵阈值，抑制低置信度乱码
-lpt -0.5  降低对数概率阈值，减少无中生有
-nf        关闭温度回退
```

- 模型路由：`small` 走轻量路线，`medium` / `large` 用于需要引用的段落

### ④ 画面文字（仅纯图 / PPT 式视频）

- 用场景切换检测抽帧 `select='gt(scene,0.3)'`，**不要固定间隔**（否则抽几十张重复帧）
- 引擎：系统 OCR（秒级，中文约 85%）/ PaddleOCR（更准但慢）

## 三、报告输出骨架（章节模板）

> 报告必须遵循「三层分离」原则：**证据层（不覆盖）→ 结构层（校订 / 时间轴）→ 解释层（事实 / 推断分层）**。
> 下面每个章节的 `【】` 是占位符，拆解时替换为实际内容；**没有证据的地方必须写「未采集」，不得臆断。**

### 标题区

```
# 内容拆解报告 · 【作品 ID】
【作品标题】

> 本报告是「忠实内容研究」，不是爆款复刻方案。事实、推断、未知均已分层标注。
```

### 一、采集范围与来源（证据层）

- 作品标识：`【ID】｜【标题】`
- 时长：`【X】s`｜标签：`【标签】`
- 简介：`【简介截断】`
- 封面：`【封面 URL】`
- 已获取：口播转写 `【N】` 段（ASR 未校订）｜弹幕采集 `【X/Y】` 条｜评论采集 `【X】` 条（顶层 `【a】` + 楼中楼 `【b】`）
- 缺失：官方分章（无）｜画面 / 镜头记录（未采集）｜音轨语速 / 重音 / 音乐（未分析）
- **交付范围：文本与互动数据拆解**（非完整音视频拆解）

### 二、语义时间轴（结构层 · 按内容转折切段，非等长）

| 时间 | 内容功能 | 起始原话摘录 |
|---|---|---|
| 【MM:SS】 | 【功能标签】 | 【原话前 40 字】 |

> 时间点为该段**起始**时间；段边界为启发式识别，需对照原音 / 画面复核。

### 三、作品内容与思想（解释层）

- **3.1 定义框架**：作者对核心概念的界定（这是该作者的界定，非普遍结论）
- **3.2 论证链**：作者如何把概念 / 案例连成结论
- **3.3 内在跳跃与风险**：绝对化判断、修辞性论断等（分析者判断，非作者观点）

### 四、表达与语言（解释层）

- **4.1 反常识 / 修辞性金句**：隐喻、对仗、反常识表达（含竞争性解释，不做单一因果）
- **4.2 表达特点**：口语化、短句、设问、案例承载等
- 语速 / 停顿 / 重音 / 音乐：**未采集音轨分析，无法判断**

### 五、受众反馈（证据层 · 样本，非整体）

- 数据口径：弹幕平台总量 `【Y】`、采集 `【X】`；评论平台总量 `【Y】`、采集 `【X】`
- 高赞评论摘要 + 关键发现
- 弹幕时间轴关键节点 + 情绪信号

### 六、互动分布与可能解释（解释层 · 非因果）

- 播放 / 点赞 / 投币 / 收藏 / 分享的比值特征
- 「可能解释」与「已证实」严格分开，不做因果断言

### 七、局限与复核项（诚实声明）

- ASR 未校订、评论未全量、画面未采集等缺口
- 待核词清单 `[听辨待核≈猜测]`

### 附录 A / B / C（证据层 · 原始数据）

- **附录 A**：口播转写（ASR 底稿，未校订，不得当作者原话引用）
- **附录 B**：弹幕原始数据（采集 `【X】` 条，平台总量 `【Y】`）
- **附录 C**：评论原始数据（采集 `【X】` 条，平台总量 `【Y】`）

## 四、自动化验收标准（7 项断言）

| 编号 | 检查项 | 不通过 = 不可交付 |
|---|---|---|
| V1 | 章节与附录齐全 | 缺任一章 / 附录 |
| V2 | 无未渲染占位符 | 残留 `{collected_dm}` 等 |
| V3 | 声明数量 == 实际行数 | 附录行数 ≠ 声明数 |
| V4 | 时间戳合法 | 逆序 / 越界 |
| V5 | 引用可回溯 | 正文引文定位不到原文 |
| V6 | 待核词不升级 | `[听辨待核]` 被当确定原话 |
| V7 | 无确定性声画断言 | 出现「镜头切换 / 配乐 / 表情」等断言 |

**退出码：0 = 全通过；1 = 存在 FAIL（产物不应标为「已交付」）。**

---

## 五、诚实边界（必须遵守，不可省略）

1. **ASR 未校订**：转写是自动结果，错词标 `[听辨待核≈猜测]`，未经回听不得当作者原话引用
2. **互动数据是采样**：弹幕 / 评论是实时采样，非全量；平台总量 ≠ 采集量，需明确口径
3. **无画面证据**：未抽帧读图时，不得生成「镜头 / 配乐 / 表情 / 剪辑节奏」等确定性断言
4. **事实 / 推断 / 因果分层**：推断不得冒充因果，相关性 ≠ 因果性
5. **新发布视频**：互动稀疏时结论需谨慎，明确标注数据稀疏

---

## 六、账号级拓展（可选，从单条 → 整个账号）

- 用搜索接口按五种排序维度交叉去重，覆盖索引可见条目
- **已知瓶颈**：只能覆盖索引可见部分（覆盖率约 3%），全量投稿需登录态（`space/wbi` 会触发 -352 / -401 风控）
- 正确路径：走 `x/space/arc/list`（旧版接口，免 WBI 签名免登录）
