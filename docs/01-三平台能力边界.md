# 三平台能力边界

> 实测时间 2026-10-29。平台接口随时会变，失效处请以实测为准。

## 为什么先讲边界

拆解的第一个动作不是采集，是承认拿不到什么。三个平台对外暴露的数据面差别极大，如果先假设「三个都能拆」，工作方案会在第一天就崩掉。

结论只有一句：**B站能拆，抖音能选题，小红书要 Key。** 三者是互补分工，不是三条平行的路。

## 每个平台该被用来干什么

### B站 —— 拆解引擎兼作品全景库

两个能力别混：

- **单条拆解**（答「为什么火」）：弹幕带秒级时间戳，官方还免费给出分章 `view_points`（含每章封面图）。这两样合起来等于一份免费的分镜表加一份免费的情绪标注，是三个平台里唯一能做时间轴归因的。
- **作品全景**（答「他怎么做到」）：`x/space/arc/list` 免 WBI 签名免登录，一次能拉全量投稿；`seasons_series_list` 给合集与系列；`navnum` 给七类形态的计数。

**差额本身是信息**：`navnum` 计数减去实际取到的数量，等于充电专属 + 已删除 + 未公开。

### 抖音 —— 选题雷达

抖音的价值不在拆解，在**预判**。热点榜免登录免签名，49 条实时词条带 `hot_value` 和 `video_count`，后者等于热点宽度——比播放量更能说明「这个话题正在铺开」。

单条内容的深度拆解需要签名或工具，性价比不高。正确的用法是：**在抖音找话题，回 B站拆内容。**

### 小红书 —— 需要 Key 的第三极

免登录路径实测不成立：详情页 302、搜索页 URL 带签名、`feeds:[]` 且 `needsRefreshAfterLogin:false`。必须引入 API Key。

唯一比另外两家强的是**正文可得**（图文笔记的文案本身就是主要内容），但这仍要 Key。

## 跨平台热点检测

三源交叉匹配，已实测可自动化：抖音热点榜 + B站热搜词 + B站排行榜标题，归一化后做包含匹配（去标点，保留中英文数字，长度 ≥ 4）。

实测命中一例：抖音热点「iPhone Duo 深度评测」↔ B站热搜「影视飓风 iPhone Duo 深度评测」↔ B站排行「折 1 万次，会坏吗？iPhone Duo 深度评测」（BV1xrnz6gEVD，194 万播放，30653 弹幕）——同一条内容三源在榜。

另一例「赛博朋克边缘行者 2 剧情评析」属于话题级共振，不是同一条内容。**区分「同一内容」与「同一话题」，前者才是热点确认。**
